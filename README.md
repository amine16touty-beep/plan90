# خطة 90 يوم

تطبيق شخصي لتتبع المهارات والعادات على مدى 90 يوم. يشتغل بدون نت ويتثبّت على الجوال والآيباد واللابتوب.

- العادات اليومية ودقائق المهارات والطاقة وسطر "وش تعلمت"
- خريطة حرارية للـ 90 يوم مقسومة على 3 مراحل (تأسيس، بناء، إطلاق)
- مراجعات أسبوعية ومراجعة لكل مرحلة
- تصدير واستيراد نسخة احتياطية
- مزامنة اختيارية بين الأجهزة عن طريق Firebase (تتفعّل بتعبئة `firebase-config.js`)

البيانات تنحفظ على جهازك أو في Firebase الخاص فيك، وما تنحفظ في هذا المستودع.
